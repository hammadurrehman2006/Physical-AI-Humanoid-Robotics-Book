# User Guide: Physical AI & Humanoid Robotics Book Chatbot

This guide explains how to use the integrated chatbot to get the most out of the Physical AI & Humanoid Robotics book.

## Getting Started

The chatbot is available as a floating button in the bottom-left corner of the book pages. Click the button to open the chat interface.

## Features

### 1. Full Book Q&A

Ask any question about the book content, and the chatbot will search through the entire book to provide an accurate answer with citations.

**Example questions:**
- "What is ROS?"
- "Explain inverse kinematics"
- "How do I create a ROS node?"

### 2. Selected Text Q&A

Select specific text on the page and click the chatbot to ask clarifying questions about that specific content.

**How to use:**
1. Highlight text you want to understand better
2. Open the chatbot (the query type will automatically switch to "Selected Text")
3. Ask your question about the selected text
4. The chatbot will provide an explanation based on the selected text and surrounding context

### 3. Conversation History

Your conversations are saved across sessions, allowing you to continue discussions later. You can access previous conversations from the conversation list.

### 4. Source Citations

All answers include citations to specific chapters and lessons in the book, so you can reference the original content for deeper understanding.

## Best Practices

### Asking Effective Questions

- Be specific: "How does TF2 work in ROS?" rather than "Tell me about ROS"
- Reference specific concepts: "What are the advantages of using MoveIt?"
- Ask follow-up questions to dive deeper into topics

### Using Selected Text

- Select concise but meaningful text snippets
- Use for clarifying complex technical concepts
- Combine with follow-up questions for deeper understanding

### Managing Conversations

- Use the conversation history to track your learning progress
- Delete conversations you no longer need to keep things organized
- Start new conversations for different topics to maintain context

## Troubleshooting

### Chatbot Not Responding

- Check your internet connection
- Verify the service is working (should show as healthy in the corner)
- Try refreshing the page

### Unclear Answers

- Ask more specific questions
- Use the selected text feature for context-specific questions
- Refer to the cited sources for more detailed information

### Slow Response Times

- Complex questions may take longer to process
- If consistently slow, try simpler questions or break complex topics into smaller questions

## Tips for Learning

1. **Use for Reinforcement**: Ask the chatbot to explain concepts you've just read to reinforce learning
2. **Explore Connections**: Ask how different concepts relate to each other
3. **Get Clarifications**: Use selected text for any confusing passages
4. **Practice Questions**: Formulate your own questions about the material to test understanding
5. **Follow Citations**: Always review the cited book sections for complete understanding

## Limitations

- The chatbot only has knowledge of the book content
- Complex multi-step problems may need additional resources
- Always verify critical information with the original book content
- The chatbot may occasionally provide incomplete answers that should be supplemented with book content
