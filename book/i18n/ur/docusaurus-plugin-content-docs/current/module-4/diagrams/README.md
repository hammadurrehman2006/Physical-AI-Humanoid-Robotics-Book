# ڈائیاگرامز

یہ سیکشن VLA (وژن لینگویج ایکشن) سسٹم کے ڈائیاگرامز اور ارکیٹیکچر کی وضاحت کرتا ہے۔

## ڈائیاگرامز کی فہرست

1. **VLA سسٹم آرکیٹیکچر** - مکمل سسٹم کی ساخت کی وضاحت کرتا ہے
2. **ڈیٹا فلو ڈائیاگرام** - ڈیٹا کے فلو کو ظاہر کرتا ہے
3. **کمپیوٹیشنل کمپونینٹس** - مختلف کمپونینٹس کے درمیان انٹرایکشن
4. **ریئل ٹائم پروسیسنگ** - ریئل ٹائم ڈیٹا پروسیسنگ کا عمل

## ڈائیاگرامز کی تفصیلات

### 1. VLA سسٹم آرکیٹیکچر
- وژن ماڈلز کی وضاحت
- لینگویج ماڈلز کی وضاحت
- ایکشن پلاننگ کمپونینٹ
- فیوژن انجن
- روبوٹ کنٹرول سسٹم

### 2. ڈیٹا فلو ڈائیاگرام
- ان پٹ ماڈلیٹیز (ویژن، آڈیو)
- انٹر میڈیٹ ریپریزنٹیشن
- آؤٹ پٹ ایکشنز
- فیڈ بیک لوپس

### 3. کمپیوٹیشنل کمپونینٹس
- GPU ایکسلریشن
- ڈیپ لارننگ ماڈلز
- ROS 2 نوڈس
- میسج پاسنگ

### 4. ریئل ٹائم پروسیسنگ
- فریم ریٹس
- لیٹنسی کنٹرول
- تھریڈ مینجمنٹ
- میموری مینجمنٹ

یہ ڈائیاگرامز VLA سسٹم کی سمجھ کو بہتر بنانے اور اس کے نفاذ کے لیے اہم ہیں۔
