# فائنل پروجیکٹ: VLA سسٹم کا مکمل نفاذ

## پروجیکٹ کا خلاصہ

اس فائنل پروجیکٹ میں، آپ کو ایک مکمل وژن لینگویج ایکشن (VLA) سسٹم کا نفاذ کرنا ہے جو انسان کی زبانی ہدایات کے مطابق ایک روبوٹ کو کام انجام دینے کے قابل بنائے۔

## پروجیکٹ کے اہداف

- وژن، لینگویج، اور ایکشن سسٹم کو مربوط کرنا
- ریئل ٹائم ڈیٹا پروسیسنگ
- سیف اور ریلائبل ایکزیکیوشن
- انسان روبوٹ انٹرایکشن کے لیے کارآمد انٹرفیس

## پروجیکٹ کی تقسیم

### حصہ 1: وژن سسٹم (30 نمبر)

#### کام کے تقاضے:
- کیمرہ فیڈ سے آبجیکٹ ڈیٹیکشن
- آبجیکٹ کی کلاسیفکیشن اور پوزیشننگ
- 3D سپیشل اندراج
- ایکشن کے لیے ٹارگٹ سلیکشن

#### تکنیکل تقاضے:
- YOLO یا دیگر ڈیٹیکشن ماڈلز
- ڈیپ لارننگ فریم ورک (PyTorch/TensorFlow)
- ROS 2 انٹیگریشن
- ریئل ٹائم پرفارمنس

### حصہ 2: لینگویج سسٹم (30 نمبر)

#### کام کے تقاضے:
- اسپیچ ٹو ٹیکسٹ کنورژن
- نیچرل لینگویج انڈر اسٹینڈنگ
- کمانڈ کی تشریح
- کنٹیکسٹ کے مطابق جواب

#### تکنیکل تقاضے:
- OpenAI Whisper یا مشابہ سپیچ ریکوگنائزر
- LLM کی انٹیگریشن (GPT یا مشابہ)
- ROS 2 میسج فارمیٹس
- کنٹیکسٹ مینجمنٹ

### حصہ 3: ایکشن سسٹم (30 نمبر)

#### کام کے تقاضے:
- ایکشن پلاننگ
- ٹریجکٹری جنریشن
- روبوٹ کنٹرول
- فیڈ بیک اور مانیٹرنگ

#### تکنیکل تقاضے:
- MoveIt 2 انٹیگریشن
- Joint trajectory control
- سیفٹی چیکس
- ایکزیکیوشن مانیٹرنگ

### حصہ 4: ملٹی ماڈل فیوژن (10 نمبر)

#### کام کے تقاضے:
- تمام ماڈلز کو مربوط کرنا
- کنٹیکسٹ کے مطابق فیصلے
- ریئل ٹائم فیوژن
- ایرر ہینڈلنگ

## تکنیکل تقاضے

### سافٹ ویئر تقاضے:
- ROS 2 Humble Hawksbill
- Python 3.10+
- PyTorch 1.12+
- OpenCV 4.5+
- NVIDIA Isaac Sim (اگر دستیاب ہو)

### ہارڈویئر تقاضے:
- NVIDIA GPU (CUDA 11.8+)
- RGB-D کیمرہ
- روبوٹ مینیپولیٹر
- مائیکروفون اری

### ارکیٹیکچر:

```
[Speech Input] -> [STT] -> [NLP] -> [Command Parser] -> [Action Planner]
     ^                                                    |
     |                                                    v
[Camera Feed] -> [Vision] -> [Object Detection] -> [Pose Estimation]
     |                                                    |
     +------------------ [Fusion Engine] <-----------------+
                              |
                              v
                    [Robot Controller] -> [Execution]
                              |
                              v
                       [Feedback Loop]
```

## ڈیلیوریبلز

### 1. کوڈ سبسیشن (50%)
- تمام ROS 2 نوڈس
- کنفیگریشن فائلیں
- لانچ فائلیں
- ڈیپینڈنسی لسٹ

### 2. دستاویزات (20%)
- سسٹم آرکیٹیکچر
- انسٹالیشن ہدایات
- استعمال کی ہدایات
- ٹیسٹنگ گائیڈ

### 3. ڈیمو (30%)
- ویڈیو ڈیمو
- کام کرتا ہوا سسٹم
- مختلف کمانڈز کی ٹیسٹنگ
- کارکردگی کے نتائج

## ٹائم لائن

- **ہفتہ 1**: پروجیکٹ کی منصوبہ بندی اور تیاری
- **ہفتہ 2-3**: وژن سسٹم کا نفاذ
- **ہفتہ 4-5**: لینگویج سسٹم کا نفاذ
- **ہفتہ 6-7**: ایکشن سسٹم کا نفاذ
- **ہفتہ 8**: فیوژن اور انٹیگریشن
- **ہفتہ 9**: ٹیسٹنگ اور ڈیمو
- **ہفتہ 10**: فائنل سبسیشن

## اسٹائل گائیڈلائنز

### کوڈنگ اسٹائل:
- PEP 8 کی پابندی
- تبصرے کے ساتھ کلیئر فنکشن ڈیفینیشنز
- ROS 2 بیسٹ پریکٹس
- ایرر ہینڈلنگ

### ROS 2 کنونشن:
- میسج فارمیٹس کی یونیفارمٹی
- ٹاپک نیم کنونشن
- لانچ فائلیں
- کنفیگریشن فائلیں

## کامیابی کے اشاریے

- سسٹم 90% کمانڈز کو درست سمجھتا ہے
- ایکزیکیوشن 85% کامیابی کے ساتھ ہوتی ہے
- ریسپانس ٹائم 5 سیکنڈ سے کم ہے
- سسٹم 1 گھنٹہ تک مستحکم کام کرتا ہے

## ایکسٹرا کریڈٹ مواقع

- ملٹی لینگویج سپورٹ
- وائس کمانڈز کی کسٹمائزیشن
- ایڈاپٹو لارننگ
- سماجی روبوٹک انٹرایکشن
