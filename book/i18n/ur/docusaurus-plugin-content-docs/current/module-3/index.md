# موڈیول 3: جسمانی AI اور ہیومنوائڈ روبوٹکس کے لیے Isaac Sim

Isaac Sim کے ساتھ جسمانی روبوٹکس ایپلی کیشنز کی ترقی کے لیے خوش آمدید، جہاں آپ ایڈوانسڈ روبوٹک سیمولیشن تخلیق کریں گے اور ہیومنوائڈ روبوٹس کے لیے جسمانی AI سسٹم ترقی دیں گے۔ یہ موڈیول بنیادی سین تخلیق سے لے کر ایڈوانسڈ کارکردگی کی اصلاح تک کو احاطہ کرتا ہے۔

## جائزہ

Isaac Sim ایک طاقتور روبوٹکس سیمولیشن پلیٹ فارم ہے جو AI-بیسڈ روبوٹکس ایپلی کیشنز کی ترقی کو فعال کرتا ہے۔ اس موڈیول میں، آپ حقیقت نما روبوٹک سیمولیشن تخلیق کرنا، سینسر سسٹم لاگو کرنا، کارکردگی کی اصلاح کرنا، اور سیمولیٹڈ ماحول میں AI ایجنٹس کو اتارنا سیکھیں گے۔

- ابتدائی کنفیگریشن اور ٹیسٹنگ

## سیکھنے کے اہداف

اس موڈیول کو مکمل کرنے کے بعد، آپ کے اہل ہوں گے:

- Isaac Sim کو روبوٹکس ترقی کے لیے سیٹ اپ اور کنفیگر کرنا
- پیچیدہ روبوٹک سیمولیشن ماحول تخلیق کرنا
- مختلف سینسر سسٹم کنفیگر کرنا اور اصلاح کرنا
- ریفورسمنٹ لرننگ پائپ لائنز لاگو کرنا اور اصلاح کرنا
- ریل ٹائم ایپلی کیشنز کے لیے سیمولیشن کارکردگی کو اصلاح کرنا
- سیمولیٹڈ ہیومنوائڈ روبوٹ ماحول میں AI ایجنٹس کو اتارنا
- سیمولیشن کی درستگی اور کارکردگی کی توثیق کرنا

## ضروریات

اس موڈیول کو شروع کرنے سے پہلے، آپ کے پاس ہونا چاہیے:

- روبوٹکس تصورات کی بنیادی سمجھ
- Python پروگرامنگ تجربہ
- مشین لرننگ تصورات سے واقفیت
- فزکس سیمولیشن کے بارے میں بنیادی علم
- ROS/ROS2 کا تجربہ (تجویز کردہ)
