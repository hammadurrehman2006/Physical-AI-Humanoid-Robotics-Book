# NVIDIA Isaac Sim کے لیے ضروریات

NVIDIA Isaac Sim ترقی میں گہرائی سے پہلے، آپ کو یقینی بنانا ہوگا کہ آپ کا سسٹم ہارڈ ویئر اور سافٹ ویئر کی ضروریات کو پورا کرتا ہے۔ Isaac Sim ایک چھاپا ڈالنے والا ایپلی کیشن ہے جس کے لیے مؤثر طریقے سے چلانے کے لیے قابل ذکر کمپیو ٹیشنل وسائل کی ضرورت ہوتی ہے۔

## ہارڈ ویئر کی ضروریات

### کم از کم ضروریات
- **CPU**: Intel Core i7 یا AMD Ryzen 7 پروسیسر (8+ کورز)
- **RAM**: 32 GB سسٹم میموری
- **GPU**: NVIDIA RTX 3080 (10GB VRAM) یا اس کے برابر
- **اسٹوریج**: 100 GB مفت ڈسک سپیس
- **OS**: Ubuntu 22.04 LTS یا Windows 10/11

### تجویز کردہ ضروریات (بہترین کارکردگی کے لیے)
- **CPU**: Intel Core i9 یا AMD Ryzen 9 پروسیسر (16+ کورز)
- **RAM**: 64 GB سسٹم میموری یا زیادہ
- **GPU**: NVIDIA RTX 4090 (24GB VRAM) یا اس کے برابر
- **اسٹوریج**: 500 GB SSD اسٹوریج
- **OS**: Ubuntu 22.04 LTS (ترقی کے لیے تجویز کردہ)

## سافٹ ویئر کی ضروریات

### آپریٹنگ سسٹم
- **Ubuntu 22.04 LTS** (ترقی کے لیے تجویز کردہ)
- **Windows 10/11** (سپورٹڈ لیکن Ubuntu کو ترجیح دی جاتی ہے)
- **Docker** (کنٹینرائزڈ Isaac Sim ڈپلائمنٹ کے لیے)

### ترقی کے ٹولز
- **Python 3.10+** (ROS 2 Humble Hawksbill مطابقت کے لیے)
- **ROS 2 Humble Hawksbill** (انسٹال اور کنفیگر کیا گیا)
- **CUDA 11.8+** (GPU ایکسلریشن کے لیے)
- **NVIDIA GPU ڈرائیورز** (تازہ ترین تجویز کردہ ورژن)
- **Git** (ورژن کنٹرول کے لیے)
- **Docker** (کنٹینرائزڈ ماحول کے لیے)

### اضافی انحصار
- **OpenGL 4.6+** سپورٹ
- **NVIDIA RTX-قابل GPU** تازہ ترین ڈرائیورز کے ساتھ
- **کافی پاور سپلائی** ہائی اینڈ GPU کے لیے (1000W+ تجویز کردہ)
- **کافی کولنگ** مسلسل GPU کمپیوٹ ورک لوڈ کے لیے

## علمی ضروریات

Isaac Sim کے ساتھ شروع کرنے سے پہلے، آپ کو مندرجہ ذیل سے واقف ہونا چاہیے:

### روبوٹکس کے تصورات
- ROS 2 کے بنیادی تصورات (نودز، ٹاپکس، سروسز، ایکشنز)
- روبوٹ کنیمیٹکس اور ڈائنا مکس
- کنٹرول سسٹم کی بنیاد
- سینسر انضمام اور ڈیٹا پروسیسنگ

### پروگرامنگ کے مہارتوں
- Python پروگرامنگ (متوسط سطح)
- C++ کی بنیادی سمجھ (مددگار ہے لیکن ضروری نہیں)
- سیمولیشن ماحول کا تجربہ (Gazebo تجربہ مددگار ہے)

### ریاضی اور AI کے تصورات
- لکیری الجبر کی بنیاد
- کمپیو ٹر وژن کے بنیادی تصورات
- مشین لرننگ کا تعارف (تاثراتی سسٹم کے لیے مددگار)

## موڈیول کی ضروریات

یہ موڈیول یہ تصور کرتا ہے کہ آپ نے مکمل کر لیا ہے:

- **موڈیول 1**: روبوٹک نروس سسٹم - ROS 2
  - ROS 2 آرکیٹیکچر کی سمجھ
  - rclpy اور ROS 2 پیکجز کا تجربہ
  - URDF اور روبوٹ ماڈلنگ کا علم

- **موڈیول 2**: ڈیجیٹل ٹوئن (Gazebo & Unity)
  - سیمولیشن ماحول کا تجربہ
  - سینسر سیمولیشن کی سمجھ
  - بنیادی فزکس سیمولیشن کے تصورات

## انسٹالیشن کی تصدیق

Isaac Sim انسٹالیشن کے ساتھ آگے بڑھنے سے پہلے، تصدیق کریں کہ آپ کا سسٹم ضروریات کو پورا کرتا ہے:

1. اپنی GPU چیک کریں:
   ```bash
   nvidia-smi
   ```

2. CUDA انسٹالیشن کی تصدیق کریں:
   ```bash
   nvcc --version
   ```

3. دستیاب سسٹم میموری چیک کریں:
   ```bash
   free -h
   ```

4. ROS 2 انسٹالیشن کی تصدیق کریں:
   ```bash
   ros2 --version
   source /opt/ros/humble/setup.bash
   ```

## اختیاری: پری-انسٹالیشن چیکس

اگر آپ Isaac Sim کو ریفورسمنٹ لرننگ یا بڑے پیمانے کی سیمولیشن کے لیے استعمال کرنا منصوبہ بند کر رہے ہیں، تو غور کریں:

- **نیٹ ورک بینڈ وڈتھ**: کلاؤڈ-مبنی Isaac Sim ڈپلائمنٹ کے لیے
- **اضافی اسٹوریج**: مصنوعی ڈیٹا جنریشن اور ماڈل تربیت کے لیے
- **بیک اپ پاور**: طویل مدتی سیمولیشن کے دوران ڈیٹا کے نقصان سے بچنے کے لیے

## اگلے اقدامات

جب آپ تصدیق کر لیں کہ آپ کا سسٹم ان ضروریات کو پورا کرتا ہے، تو آپ اگلے حصے میں انسٹالیشن گائیڈ پر عمل کر سکتے ہیں۔ انسٹالیشن کا عمل آپ کو ہیومنوائڈ روبوٹکس ترقی کے لیے مناسب کنفیگریشن کے ساتھ Isaac Sim سیٹ کرنے کے عمل سے گزارے گا۔
