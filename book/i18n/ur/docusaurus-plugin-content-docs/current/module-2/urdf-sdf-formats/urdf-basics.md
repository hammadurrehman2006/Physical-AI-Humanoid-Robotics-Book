# یوآرڈی ایف کی بنیاد: روبوٹ کی تفصیل کا فارمیٹ

یوآرڈی ایف (یونیفائیڈ روبوٹ ڈسکرپشن فارمیٹ) ایک XML فارمیٹ ہے جو ROS میں روبوٹ ماڈلز کی تفصیل کے لیے استعمال ہوتا ہے۔ یہ روبوٹ کی فزیکل اور وژول خصوصیات کو بیان کرتا ہے، بشمول لنکس، جوائنٹس، اور سینسرز۔

## یوآرڈی ایف سٹرکچر کو سمجھنا

ایک بنیادی یوآرڈی ایف فائل میں یہ شامل ہوتا ہے:
- **لنکس**: روبوٹ کے سخت حصے (جیسے، چیسیس، پہیے)
- **جوائنٹس**: لنکس کے درمیان رابطے (جیسے، ہنجز، سلائیڈرز)
- **وژول**: سیمولیشن میں روبوٹ کیسے نظر آتا ہے
- **کولیژن**: فزیکل کولیژن کی خصوصیات
- **انرشل**: فزکس سیمولیشن کے لیے ماس اور انرشیا کی خصوصیات

## بنیادی یوآرڈی ایف مثال

```xml
<?xml version="1.0"?>
<robot name="simple_robot">
  <!-- بیس لنک -->
  <link name="base_link">
    <visual>
      <geometry>
        <box size="0.5 0.5 0.2"/>
      </geometry>
      <material name="blue">
        <color rgba="0 0 1 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <box size="0.5 0.5 0.2"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="1"/>
      <inertia ixx="0.1" ixy="0" ixz="0" iyy="0.1" iyz="0" izz="0.1"/>
    </inertial>
  </link>
</robot>
```

## کلیدی اجزاء

### لنکس
لنکس روبوٹ میں سخت اجسام کی نمائندگی کرتے ہیں۔ ہر لنک کے پاس ہونا چاہیے:
- ایک منفرد نام
- وژول خصوصیات (شکل، رنگ، میش)
- کولیژن کی خصوصیات
- انرشل کی خصوصیات

### جوائنٹس
جوائنٹس لنکس کو جوڑتے ہیں اور بیان کرتے ہیں کہ وہ ایک دوسرے کے ساتھ کیسے حرکت کر سکتے ہیں:
- **فکسڈ**: کوئی حرکت نہیں (ویلڈ)
- **ریوولوٹ**: حدود کے ساتھ گھوماؤ حرکت
- **کنٹینیوئس**: لامحدود گھوماؤ حرکت
- **پرزمیٹک**: لکیری سلائیڈنگ حرکت
- **فلوٹنگ**: 6DOF حرکت (کوئی پابندیاں نہیں)

## اپنا پہلا یوآرڈی ایف بنانا

چلو ایک سادہ روبوٹ بنائیں جس کا ایک بیس اور ایک گھومنے والا پہیہ ہو:

```xml
<?xml version="1.0"?>
<robot name="wheel_robot">
  <!-- روبوٹ کا بیس -->
  <link name="base_link">
    <visual>
      <geometry>
        <box size="0.8 0.4 0.2"/>
      </geometry>
      <material name="light_grey">
        <color rgba="0.7 0.7 0.7 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <box size="0.8 0.4 0.2"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="2"/>
      <inertia ixx="0.1" ixy="0" ixz="0" iyy="0.1" iyz="0" izz="0.1"/>
    </inertial>
  </link>

  <!-- پہیہ لنک -->
  <link name="wheel">
    <visual>
      <geometry>
        <cylinder radius="0.1" length="0.05"/>
      </geometry>
      <origin rpy="1.57075 0 0"/> <!-- روبوٹ کے ساتھ ہم آہنگ کرنے کے لیے گھمائیں -->
      <material name="black">
        <color rgba="0 0 0 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <cylinder radius="0.1" length="0.05"/>
      </geometry>
      <origin rpy="1.57075 0 0"/>
    </collision>
    <inertial>
      <mass value="0.2"/>
      <inertia ixx="0.001" ixy="0" ixz="0" iyy="0.001" iyz="0" izz="0.001"/>
    </inertial>
  </link>

  <!-- بیس کو پہیہ سے جوڑنے والا جوائنٹ -->
  <joint name="wheel_joint" type="continuous">
    <parent link="base_link"/>
    <child link="wheel"/>
    <origin xyz="0 0 -0.1"/>
    <axis xyz="0 0 1"/>
  </joint>
</robot>
```

## گیزبو میں یوآرڈی ایف لوڈ کرنا

اپنے یوآرڈی ایف کو گیزبو میں لوڈ کرنے کے لیے:

1. اپنی یوآرڈی ایف فائل کو `.urdf` ایکسٹینشن کے ساتھ محفوظ کریں
2. گیزبو کے لیے ایس ایس ڈی فارمیٹ میں تبدیل کریں:
   ```bash
   gz sdf -p your_robot.urdf
   ```
3. گیزبو میں لوڈ کریں:
   ```bash
   gz sim -r your_robot.sdf
   ```

## بہترین طریقے

- لنکس اور جوائنٹس کے لیے معنی خیز نام استعمال کریں
- فزکس سیمولیشن کے لیے ہمیشہ انرشل خصوصیات کی وضاحت کریں
- وژول اور کولیژن جیومیٹریز کو مسلسل رکھیں
- پیچیدہ روبوٹس کے لیے الگ فائلز استعمال کریں اور انہیں `<xacro>` کے ساتھ شامل کریں (مزید ایڈوانسڈ)
