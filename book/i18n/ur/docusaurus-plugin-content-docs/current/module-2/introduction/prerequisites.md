# گیزبو اور یونٹی سیمولیشن کے لیے شرائط لازمہ

موڈیول 2 شروع کرنے سے پہلے، یقینی بنائیں کہ آپ نے درج ذیل شرائط لازمہ مکمل کر لی ہیں:

## ضروری علم

- [موڈیول 1: ROS 2 فنڈامینٹلز](/docs/module-1) - ROS 2 تصورات کی مکمل سمجھ
- بنیادی پائی تھون پروگرامنگ کا علم (پائی تھون 3.10+)
- کمانڈ لائن ٹولز سے واقفیت
- بنیادی روبوٹکس تصورات کی سمجھ

## سافٹ ویئر کی ضروریات

### ROS 2 انسٹالیشن
- ROS 2 ہمبول ہاکسبل انسٹال اور کام کر رہا ہو
- انسٹالیشن کی تصدیق: `ros2 --version`

### سسٹم کی ضروریات
- اوبنٹو 22.04 ایل ٹی ایس (بنیادی ہدف) یا مطابقت رکھنے والا سسٹم
- کم از کم 8 جی بی ریم (یونٹی کے لیے 16 جی بی تجویز کردہ)
- یونٹی وژولائزیشن کے لیے جدید جی پی یو تجویز کردہ
- سیمولیشن ماحول کے لیے کم از کم 10 جی بی خالی ڈسک کی جگہ

## انسٹالیشن کی تصدیق

آگے بڑھنے سے پہلے، اپنا ماحول تصدیق کریں:

```bash
# ROS 2 انسٹالیشن چیک کریں
source /opt/ros/humble/setup.bash
ros2 --version

# گیزبو کے لیے چیک کریں (اگلے حصے میں انسٹالیشن کا احاطہ کیا جائے گا)
gz --version
```

جب آپ یقین کر لیں کہ تمام شرائط لازمہ پوری ہو گئی ہیں، تو [گیزبو ماحول کو سیٹ اپ کرنا](./setup-gazebo-environment.md) پر جاری رکھیں تاکہ اپنی سیمولیشن کی سفر شروع کر سکیں۔
