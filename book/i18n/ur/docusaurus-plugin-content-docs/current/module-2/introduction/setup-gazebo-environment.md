# گیزبو ماحول کو سیٹ اپ کرنا

یہ ٹیوٹوریل آپ کو روبوٹکس ڈیولپمنٹ کے لیے اپنے گیزبو سیمولیشن ماحول کو سیٹ اپ کرنے میں رہنمائی فراہم کرے گا۔

## شرائط لازمہ

- ROS 2 ہمبول ہاکسبل
- مطابقت رکھنے والا اوبنٹو ورژن (22.04 ایل ٹی ایس تجویز کردہ)
- کم از کم 8 جی بی ریم

## انسٹالیشن اقدامات

### 1. گیزبو گارڈن انسٹال کریں

اوبنٹو 22.04 کے لیے:

```bash
# پیکیج لسٹ اپ ڈیٹ کریں
sudo apt update

# گیزبو گارڈن انسٹال کریں
sudo apt install gazebo

# متبادل: مخصوص گارڈن ورژن انسٹال کریں
sudo apt install gazebo-garden
```

### 2. انسٹالیشن کی تصدیق کریں

```bash
# گیزبو ورژن چیک کریں
gz --version

# بنیادی گیزبو لانچ کا ٹیسٹ کریں
gz sim
```

### 3. بنیادی سیمولیشن کا ٹیسٹ کریں

```bash
# خالی دنیا کے ساتھ گیزبو لانچ کریں
gz sim -r empty.sdf

# دوسرے ٹرمنل میں، یقین کریں کہ آپ سیمولیشن سے رابطہ قائم کر سکتے ہیں
gz topic -l
```

## مسئلہ حل کرنا

### عام مسائل

1. **گیزبو گرافکس کی خرابیوں کے ساتھ لانچ کرنے میں ناکام ہو جاتا ہے**:
   - یقینی بنائیں کہ آپ کے پاس مناسب گرافکس ڈرائیورز انسٹال ہیں
   - سافٹ ویئر رینڈرنگ کے ساتھ چلانے کی کوشش کریں: `export MESA_GL_VERSION_OVERRIDE=3.3; gz sim`

2. **وابستگیاں غائب ہیں**:
   - یقینی بنائیں کہ تمام پیکیجز موجود ہیں: `sudo apt update && sudo apt upgrade`
   - غائب ROS 2 وابستگیاں انسٹال کریں: `sudo apt install ros-humble-gazebo-*`

3. **اجازت کے مسائل**:
   - یقینی بنائیں کہ آپ کا صارف ڈائل آؤٹ گروپ میں ہے: `sudo usermod -a -G dialout $USER`
   - تبدیلیاں لاگو ہونے کے لیے لاگ آؤٹ اور دوبارہ لاگ ان کریں

## اگلے اقدامات

گیزبو کو کامیابی سے سیٹ اپ کرنے کے بعد، [یوآرڈی ایف اور ایس ڈی ایف روبوٹ کی تفصیل کے فارمیٹس](../urdf-sdf-formats/urdf-basics.md) کے بارے میں سیکھنے کے لیے جاری رکھیں۔
