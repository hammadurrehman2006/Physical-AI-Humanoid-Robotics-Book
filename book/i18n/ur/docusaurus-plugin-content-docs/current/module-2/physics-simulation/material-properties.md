# میٹریل کی خصوصیات اور فزکس پیرامیٹرز

یہ ٹیوٹوریل گیزبو سیمولیشنز میں میٹریل کی خصوصیات اور فزکس پیرامیٹرز کو کنفیگر کرنے کو دیکھتا ہے۔ آپ سیکھیں گے کہ فریکشن، ریسٹی ٹوشن، اور دیگر فزیکل خصوصیات کو کیسے ایڈجسٹ کرنا ہے تاکہ حقیقی سیمولیشن ماحول تخلیق کیا جا سکے۔

## میٹریل کی خصوصیات

گیزبو میں، آپ مختلف میٹریل کی خصوصیات کی وضاحت کر سکتے ہیں جو اشیاء کے تعامل کو متاثر کرتی ہیں:

- **فریکشن کوائف** - اشیاء ایک دوسرے کے خلاف کیسے سلائیڈ کرتی ہیں
- **ریسٹی ٹوشن** - کولیژن کے دوران اشیاء کی باؤنسی نیس
- **کثافت** - اشیاء میں ماس کی تقسیم

## فزکس انجن کنفیگریشن

گیزبو متعدد فزکس انجن کی حمایت کرتا ہے جن کی مختلف صلاحیات ہیں:

- ODE (پن ڈائنامکس انجن)
- بُلیٹ
- DART (ڈائنامک اینیمیشن اور روبوٹکس ٹول کٹ)

## کنفیگریشن کی مثالیں

URDF اور SDF دونوں فارمیٹس میں فزکس خصوصیات کو کنفیگر کرنے کی مثالیں۔

## فزکس پیرامیٹرز کی جانچ

طریقے جن کے ذریعے آپ تصدیق کر سکتے ہیں کہ آپ کے فزکس پیرامیٹرز حقیقی برتاؤ پیدا کرتے ہیں۔
