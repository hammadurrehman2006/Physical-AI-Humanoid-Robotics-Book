# مارک ڈاؤن خصوصیات

Docusaurus **[مارک ڈاؤن](https://daringfireball.net/projects/markdown/syntax)** اور چند **اضافی خصوصیات** کو سپورٹ کرتا ہے۔

## فرنٹ میٹر (Front Matter)

مارک ڈاؤن دستاویزات کے اوپر میٹا ڈیٹا ہوتا ہے جسے [فرنٹ میٹر](https://jekyllrb.com/docs/front-matter/) کہا جاتا ہے:

```text title="my-doc.md"
// highlight-start
---
id: my-doc-id
title: My document title
description: My document description
slug: /my-custom-url
---
// highlight-end

## Markdown heading

Markdown text with [links](./hello.md)
```

## لنکس

باقاعدہ مارک ڈاؤن لنکس کو سپورٹ کیا جاتا ہے، یو آر ایل پاتھ یا متعلقہ فائل پاتھ کا استعمال کرتے ہوئے۔

```md
Let's see how to [Create a page](/create-a-page).
```

```md
Let's see how to [Create a page](./create-a-page.md).
```

**نتیجہ:** آئیے دیکھتے ہیں کہ [صفحہ کیسے بنایا جائے](./create-a-page.md)۔

## تصاویر

باقاعدہ مارک ڈاؤن تصاویر کو سپورٹ کیا جاتا ہے۔

آپ اسٹیٹک ڈائرکٹری (`static/img/docusaurus.png`) میں تصاویر کا حوالہ دینے کے لیے مطلق راستے استعمال کر سکتے ہیں:

```md
![Docusaurus logo](/img/docusaurus.png)
```

![Docusaurus logo](/img/docusaurus.png)

آپ موجودہ فائل سے متعلقہ تصاویر کا حوالہ بھی دے سکتے ہیں۔ یہ خاص طور پر ان تصاویر کو مارک ڈاؤن فائلوں کے قریب رکھنے کے لیے مفید ہے جو انہیں استعمال کر رہی ہیں:

```md
![Docusaurus logo](./img/docusaurus.png)
```

## کوڈ بلاکس

مارک ڈاؤن کوڈ بلاکس کو سنٹیکس ہائی لائٹنگ کے ساتھ سپورٹ کیا جاتا ہے۔

````md
```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```
````

```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```

## تنبیہات (Admonitions)

Docusaurus میں تنبیہات اور کال آؤٹس بنانے کے لیے ایک خاص سنٹیکس ہے:

```md
:::tip My tip

Use this awesome feature option

:::

:::danger Take care

This action is dangerous

:::
```

:::tip My tip

Use this awesome feature option

:::

:::danger Take care

This action is dangerous

:::

## MDX اور React اجزاء

[MDX](https://mdxjs.com/) آپ کی دستاویزات کو مزید **انٹرایکٹو** بنا سکتا ہے اور **مارک ڈاؤن کے اندر کسی بھی React اجزاء** کو استعمال کرنے کی اجازت دیتا ہے:

```jsx
export const Highlight = ({children, color}) => (
  <span
    style={{
      backgroundColor: color,
      borderRadius: '20px',
      color: '#fff',
      padding: '10px',
      cursor: 'pointer',
    }}
    onClick={() => {
      alert(`You clicked the color ${color} with label ${children}`)
    }}>
    {children}
  </span>
);

This is <Highlight color="#25c2a0">Docusaurus green</Highlight> !

This is <Highlight color="#1877F2">Facebook blue</Highlight> !
```
