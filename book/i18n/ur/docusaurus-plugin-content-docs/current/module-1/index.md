# مODULE 1: روبوٹک نروس سسٹم - ROS 2

## ROS 2 کا تعارف

مODULE 1 میں خوش آمدید، جہاں ہم جدید روبوٹکس کی پشت پر چلنے والی چیز کا جائزہ لیں گے: ROS 2 (روبوٹ آپریٹنگ سسٹم 2)۔ بالکل اسی طرح جیسے حیاتیاتی جانداروں میں نروس سسٹم اعمال کو منظم کرتا ہے، ROS 2 وہ مواصلاتی بنیاد فراہم کرتا ہے جس کی بدولت روبوٹک سسٹم مربوط طور پر کام کر سکتے ہیں۔

### ROS 2 کیا ہے؟

ROS 2 روبوٹ سافٹ ویئر لکھنے کے لیے ایک لچکدار فریم ورک ہے۔ یہ اوزاروں، لائبریریز، اور رواج کا ایک مجموعہ ہے جو کہ مختلف قسم کے روبوٹ پلیٹ فارمز پر پیچیدہ اور مستحکم روبوٹ کے رویے کو تخلیق کرنے کے کام کو آسان بنانے کا مقصد رکھتا ہے۔

### سیکھنے کے اہداف

اس مODULE کے اختتام تک آپ:
- ROS 2 کی بنیادی تعمیر سیکھ لیں گے
- روبوٹک سسٹم میں نوڈس، ٹاپکس، سروسز، اور ایکشنز کو سمجھیں گے
- Python ایجنٹس کو rclpy کے ذریعے ROS کنٹرولرز سے جوڑنے کا طریقہ سیکھیں گے
- اپنے پہلے ROS 2 پیکجز بنائیں گے
- لانچ فائلز اور پیرامیٹرز کے ساتھ کام کریں گے
- ہیومنوائڈ روبوٹس کے لیے URDF کو سمجھیں گے

### مODULE کی ساخت

یہ مODULE کئی سبقوں میں تقسیم ہے، ہر ایک ROS 2 کے ایک مخصوص پہلو پر توجہ مرکوز کرتا ہے:

1. **ROS 2 آرکیٹیکچر**: بنیادی تصورات اور ڈیزائن کے اصولوں کو سمجھنا
2. **نوڈس، ٹاپکس، اور سروسز**: ROS 2 میں مواصلاتی نمونے
3. **روبوٹک سسٹم میں ایکشنز**: طویل مدتی کام اور فیڈ بیک کے طریقے
4. **Python-rclpy برج**: Python ایجنٹس کو ROS کنٹرولرز سے منسلک کرنا
5. **ROS 2 پیکجز بنانا**: ماڈیولر اور دوبارہ استعمال کے قابل کوڈ بنانا
6. **لانچ فائلز اور پیرامیٹرز**: پیچیدہ روبوٹک سسٹم کا نظم کرنا
7. **ہیومنوائڈز کے لیے URDF**: ہیومنوائڈ سسٹم کے لیے روبوٹ کی تفصیل

### شرائطِ لازمہ

اس مODULE کو شروع کرنے سے پہلے، آپ کے پاس ہونا چاہیے:
- تعارف سیکشن مکمل ہو
- Python 3.10+ انسٹال ہو
- روبوٹکس کے تصورات کی بنیادی سمجھ
- کمانڈ لائن ٹولز سے واقفیت

### جائزہ پراجیکٹ

اس مODULE کے اختتام پر، آپ ایک جامع جائزہ پراجیکٹ مکمل کریں گے جو اس مODULE میں سیکھے گئے تمام تصورات کو اکٹھا کرتا ہے، ROS 2 کے بنیادی تصورات کی آپ کی سمجھ کو ظاہر کرتا ہے۔
